# 田野拍攝指南

## 標準流程（約 20 秒）

```
前 5 秒   參照物碰到樹幹 → 靜止特寫
往上掃 5 秒  從胸高掃到有葉子的枝條
（選做）繞樹 90–120°  持續對準胸高
```

---

## 第一段：參照物特寫（5 秒，必做）

**目的：Route A 精確 DBH + 訓練支柱二修正因子**

- 把任何已知尺寸物件**碰到樹幹**（接觸即可，不需固定高度）
- 相機距樹幹 **2–3 公尺**，靜止不動
- 胸高（距地 **1.3 公尺**）盡量在畫面內

**可用的參照物（任選一種）：**

| 物件 | 代表尺寸 | 備註 |
|------|---------|------|
| 信用卡 / 金融卡 / 悠遊卡 | 85.6 mm | 最方便攜帶 |
| 台灣標準名片 | 90 mm | |
| A4 紙 | 210 mm | 對折後 A5 = 148 mm |
| A5 紙 | 148 mm | |
| B5 筆記本 | 182 mm | |
| 30 cm 直尺 | 300 mm | |
| 1 m 直尺 | 1000 mm | |
| 台幣 100 元紙鈔 | 130 mm | |
| 台幣 500 元紙鈔 | 154 mm | |
| 台幣 1000 元紙鈔 | 160 mm | |
| 其他已知尺寸物件 | 自行估算 | Gemini 會辨識 |

> **關鍵原則：參照物只要碰到樹幹就有效，不需特定高度。**
> 放在樹幹根部地板也可以，靠著樹皮即可。

**不建議：**
- 參照物放在離樹幹遠的地板或背景
- 手持參照物站在相機旁邊（深度不同，比例會錯）

---

## 第二段：往上掃（5 秒，必做）

**目的：PlantNet / iNaturalist 樹種辨識**

- 從胸高位置慢速往上掃到有葉子的枝條
- 讓葉片清楚出現在畫面內（Gemini 會自動標注有葉片的幀）
- 慢速移動，避免動態模糊

---

## 第三段：繞樹（選做，10–15 秒）

**目的：Route B 多角度備援 + 降低距離估算誤差**

- 相機高度維持約 **1.3 公尺**（胸高）
- 相機距樹幹維持 **2–3 公尺**
- 持續對準樹幹胸高部位
- 繞 **90–120°** 即可，不需整圈
- 慢速移動，避免模糊

> 這段讓系統從多個角度取 distanceStdPct 較低的中位數，
> 提高 confidence 等級。

---

## 最高精度做法：捲尺直接讀數（Route 0）

若要得到最準確的 ground truth：

1. 用捲尺繞樹幹一圈（胸高處）
2. 相機對準讀數（確保數字清晰可見）
3. 系統自動讀取：DBH = 周長讀數 ÷ π

或用直尺直接量直徑：DBH = 讀數直接使用。

---

## 樹幹分岔的處理

| 情況 | 量測位置 |
|------|---------|
| 分岔在 1.3 m 以下 | 量分岔前的主幹 |
| 分岔在 1.3 m 以上 | 量最粗的主幹（胸高處） |

---

## 測量路徑優先順序

```
路徑 0  捲尺/直尺直接讀數          → confidence: high（最高精度）
路徑 A  參照物倍數比較              → confidence: high
路徑 B  薄透鏡公式（無參照物）      → confidence: low / medium
路徑 B  + 修正因子（累積 ≥ 5 棵）  → confidence: medium / high
```

---

## 單人操作建議

| 方法 | 做法 |
|------|------|
| 膠帶固定 | 事先用膠帶把卡片貼在樹幹 1.3 m 高 |
| 根部放置 | 把 A4 紙靠在樹幹根部地板，碰到樹皮即可 |
| 自拍棒 | 固定相機，雙手空出來持參照物 |
