# 林業碳匯自動測量系統：核心概念

## 三支柱架構

```
支柱一：AI 測量管道          支柱二：修正因子演進帳本       支柱三：區塊鏈存證
─────────────────────        ──────────────────────────      ──────────────────
手機影片上傳                  Route A 累積真值                Besu QBFT 私鏈
  ↓                           ↓                               每筆測量上鏈
FFmpeg 擷取關鍵幀              比較 Route A vs Route B         tx_hash 存入 DB
  ↓                           ↓                               影片 SHA-256 上鏈
Gemini 視覺分析                計算修正因子（per-species）
  ↓                           ↓
路徑 A 或 路徑 B 計算          下次 Route B 測量自動套用
  ↓
DBH → 材積 → 碳儲量
```

## 支柱一：兩條測量路徑

### 路徑 A（有實體參照物，精確模式）

拍攝前將已知尺寸物件貼在胸高位置（距地 1.3m）：
- 信用卡：85.6mm × 53.98mm
- A4 紙：210mm × 297mm
- 30cm 直尺、1m 直尺

**計算方式（倍數比較）**：
```
Gemini 回答：「樹幹寬度是參照物寬度的 N 倍」
DBH = N × 參照物寬度（mm） ÷ 10
```

例：A4 短邊 210mm，N = 0.18 → DBH = 0.18 × 210 / 10 = 3.78cm
例：A4 短邊 210mm，N = 1.8  → DBH = 1.8 × 210 / 10 = 37.8cm ✓

誤差目標：MAPE ≤ 5%（與捲尺比較）

### 路徑 B（無參照物，薄透鏡備援）

```
DBH = (trunkWidthFraction × imageWidth × sensorWidthMm × distanceM × 1000)
      ÷ (imageWidth × focalLengthMm)
    = trunkWidthFraction × sensorWidthMm × distanceM × 1000 / focalLengthMm
```

- `trunkWidthFraction`：Gemini 估算樹幹佔畫面寬度比例（0.0–1.0）
- 誤差大（±30%+），依賴 Gemini 的距離估算
- 但**套用修正因子後**可改善

## 支柱二：修正因子自演進機制

### 核心邏輯

**當同一支影片走路徑 A（有參照物）時，系統同時計算路徑 B 的估算值：**

```
Route A（真值）  = 37.8 cm
Route B（估算） = 175  cm（薄透鏡，Gemini 距離估算誤差大）

修正因子 = Route A ÷ Route B = 37.8 ÷ 175 = 0.216
```

寫入 ground_truth 表：
```
actualDbhCm    = 37.8   （Route A 的精確值）
estimatedDbhCm = 175    （Route B 若沒有參照物的估算值）
```

### 修正因子如何累積收斂

| 樣本數 | 動作 |
|--------|------|
| 1–4 棵 | 累積中，尚未套用 |
| ≥5 棵  | 開始套用中位數修正因子 |
| 更多   | 因子持續更新，收斂到穩定值 |

### 套用修正因子（無參照物的影片）

```
DBH_corrected = Route B 估算 × 修正因子
              = 175 × 0.216
              ≈ 37.8 cm ✓
```

### 關鍵設計原則

**Route A 不只是量那棵樹，更是在訓練支柱二如何修正支柱一的路徑 B 偏差。**

每一棵有參照物的影片 = 一筆訓練資料，讓系統越來越準確。

## 支柱三：區塊鏈存證

- 平台：Hyperledger Besu QBFT 私有鏈（Chain ID 1337，GCP 三節點）
- 合約：CarbonCredit.sol
- 每筆測量記錄：GPS、樹種、DBH（mm）、材積（cm³×100）、碳重（g）、影片 SHA-256
- tx_hash 寫回 trees.tx_hash，保證可追溯性

---

## 資料流整體示意

```
影片上傳
  │
  ├─ SHA-256 雜湊（去重）
  ├─ ExifTool 擷取 GPS / 焦距 / 感光元件寬
  ├─ FFmpeg 擷取關鍵幀
  ├─ PlantNet + iNaturalist 樹種辨識（Gemini 備援）
  │
  ├─ Gemini 視覺分析 ──────────────────────────────┐
  │   ├─ 有參照物 → trunkToReferenceRatio          │
  │   └─ 無論如何 → trunkWidthFraction（備援用）   │
  │                                                 │
  ├─ 計算服務 ◄──────────────────────────────────┘
  │   ├─ Route A：ratio × refMm → 精確 DBH
  │   ├─ Route B：薄透鏡公式 → 估算 DBH（修正因子備存）
  │   └─ 修正因子套用（Route B 且已有足夠樣本時）
  │
  ├─ 寫入 SQLite（trees + ground_truth + correction_factor_log）
  └─ 上鏈（Besu）→ tx_hash 回存 trees 表
```
